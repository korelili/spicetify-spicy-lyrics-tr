## <img src="https://flagcdn.com/w40/gb.png" alt="United Kingdom flag" width="28" height="21"> English
### Understand the words. Stay in the music.

**Spicy Lyrics AI Translator & Romaja** adds Turkish translations and romanized pronunciations beneath the original lyrics in **Spicy Lyrics**. Follow the song, discover what the words mean, and enjoy the original language—all in one beautiful view.

### ✨ What makes it special?
- **Three layers, one experience** — See the original lyrics, pronunciation guides for supported languages, and Turkish translations together.
- **A little more meaning** — Choose optional Gemini AI-assisted translation for a more natural reading of the song's expressions and mood.
- **Your AI keys, your choice** — Add and manage multiple Gemini API keys in one place. The extension handles temporary service limits and waiting periods when possible.
- **Quality when it matters** — An optional quality setting can avoid lower-quality backup translations when Gemini is unavailable.
- **Made to be readable** — Enjoy a clean, comfortable lyric display without covering the original words.
- **Ready when you replay** — Previously translated lyrics are saved locally so they can load faster the next time you listen.

### 🎛️ The TR / AI button

**Right-click the TR / AI button** in the Spicy Lyrics controls to open translation settings:

- **Add or update Gemini API keys** — Enter one or more keys, separated by commas or new lines.
- **Choose your quality preference** — Decide whether backup translations should be used when Gemini is unavailable.
- **Save (`Kaydet`)** — Keep your settings and existing saved translations.
- **Reset cache (`Önbelleği sıfırla`)** — Clear all saved lyric translations and pronunciation data so they can be generated again. This can use more API quota; your saved API keys are retained.

The button also displays translation mode and temporary availability information. **A Gemini API key is optional:** basic translation is available without one.

> **Good to know:** Gemini usage limits are set by Google and may be shared by keys belonging to the same project. Adding more keys does not guarantee more quota. Translation and pronunciation availability can vary by song and language.

### 🎧 Start listening

1. Make sure **Spicy Lyrics** is installed in Spicetify.
2. Open **Spicetify Marketplace → Extensions**, search for **Spicy Lyrics AI Translator & Romaja**, and install it.
3. Open the lyrics. Right-click the **TR / AI** button if you want to add Gemini API keys, adjust quality settings, or manage saved translations.

## <img src="https://flagcdn.com/w40/tr.png" alt="Türkiye flag" width="28" height="21"> Türkçe

### Sözleri anla. Müziğin içinde kal.

**Spicy Lyrics AI Translator & Romaja**, **Spicy Lyrics** üzerinde şarkı sözlerinin hemen altına Türkçe çeviriler ve Latin harfleriyle okunuşlar ekler. Orijinal sözleri kaybetmeden şarkıyı takip et, anlamını keşfet ve müziğin keyfini çıkar.

### ✨ Neler sunuyor?
- **Üç katman, tek deneyim** — Orijinal sözleri, desteklenen dillerde okunuşlarını ve Türkçe çevirilerini aynı anda gör.
- **Sözlerin ardındaki anlam** — İsteğe bağlı Gemini yapay zekâ çevirisiyle ifadeleri ve şarkının duygusunu daha doğal şekilde keşfet.
- **Birden fazla API anahtarı** — Gemini API anahtarlarını tek bir yerden ekle ve yönet. Eklenti, geçici servis sınırlarını ve bekleme sürelerini mümkün olduğunca dikkate alır.
- **Çeviri kalitesini seç** — İsteğe bağlı kalite ayarıyla Gemini kullanılamadığında daha düşük kaliteli yedek çevirilerin gösterilmesini önle.
- **Göz yormayan görünüm** — Orijinal sözleri gizlemeyen, temiz ve rahat okunan bir şarkı sözü deneyimi yaşa.
- **Tekrar dinlemeye hazır** — Daha önce çevrilen şarkıların sözleri yerel olarak saklanır ve sonraki dinleyişlerde daha hızlı gösterilebilir.

### 🎛️ TR / AI düğmesi

Çeviri ayarlarını açmak için Spicy Lyrics kontrol çubuğundaki **TR / AI düğmesine sağ tıkla**:

- **Gemini API anahtarı ekle veya güncelle** — Birden fazla anahtarı virgülle veya alt alta yazarak girebilirsin.
- **Kalite tercihini belirle** — Gemini kullanılamadığında yedek çevirilerin kullanılıp kullanılmayacağını seç.
- **Kaydet** — Ayarları kaydederken mevcut çevirileri korur.
- **Önbelleği sıfırla** — Kayıtlı bütün şarkı sözü çevirilerini ve okunuş verilerini siler; gerektiğinde yeniden oluşturulurlar. Bu işlem yeniden API kotası tüketebilir, ancak kayıtlı API anahtarlarını silmez.

Düğme ayrıca çeviri modunu ve geçici erişim durumunu gösterir. **Gemini API anahtarı zorunlu değildir:** temel çeviri anahtar eklemeden de kullanılabilir.

> **Küçük bir not:** Gemini kullanım sınırlarını Google belirler. Aynı projeye bağlı API anahtarları kotayı paylaşabilir; daha fazla anahtar eklemek mutlaka daha fazla kota sağlamaz. Çeviri ve okunuş desteği şarkıya ve dile göre değişebilir.

### 🎧 Dinlemeye başla

1. Spicetify'da **Spicy Lyrics** eklentisinin kurulu olduğundan emin ol.
2. **Spicetify Marketplace → Extensions** bölümünde **Spicy Lyrics AI Translator & Romaja** adını ara ve yükle.
3. Şarkı sözlerini aç. Gemini API anahtarı eklemek, kalite tercihini değiştirmek veya kayıtlı çevirileri yönetmek için **TR / AI düğmesine sağ tıkla**.
